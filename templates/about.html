ℹ About MentoraX AI

An intelligent academic diagnostic system built for students and educators.

🎯 Project Overview

MentoraX AI is a web-based academic performance analyser built as a final year project. It goes beyond simply showing marks — it uses a heuristic diagnostic engine to find correlations between study habits and exam results, and a Groq-powered LLM to generate truly personalised recommendations and study plans.

The core idea: raw marksheets tell you what happened, but MentoraX tells you why — and more importantly, what to do next.

🧩 System Modules

M1

Biometric Authorization

Simulates fingerprint-based student identity verification with an animated scanner UI. Sets a secure session for the duration of the analysis.

M2

Data Acquisition + OCR

Students can upload a marksheet image — Tesseract OCR (v4.1) extracts marks, student ID, and subject automatically. Or data can be entered manually.

M3

Heuristic Diagnostic Engine

Rule-based engine calculates the performance percentage, classifies into Excellent / Average / Alert tier, and maps correlations between behavioral metrics and results.

AI

Groq LLM Analysis llama-3.3-70b-versatile

The student's data and heuristic findings are sent to Groq's API. The LLM returns a personalised summary, 5 actionable recommendations, and a 5-day study plan in under 2 seconds.

M4

Neural HUD Dashboard

Chart.js renders interactive doughnut and bar charts. All analysis results, correlations, and AI insights are displayed in a cyberpunk-themed dark UI.
